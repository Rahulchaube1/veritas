# Operating the research service

The default bind address is loopback. A network listener through the CLI requires production mode and a bearer token of at least 24 characters. Set the token through the environment. Terminate TLS at a trusted proxy for remote use. All API operations share one trust level, including indexing. Give tokens only to trusted operators. The browser keeps the token in the current page and sends it in an authorization header.

The application treats passages as plain text. It never executes document instructions or follows indexed URLs. The optional SearXNG command calls one operator-configured HTTPS endpoint, refuses redirects and saves bounded provider snippets. Use an instance you are authorized to query. No document crawling, private web access, or network access during ordinary search is required.

Requests have byte, corpus and step limits. The single compute worker declines concurrent jobs. When the response deadline expires, a computation already running finishes in its worker and continues to occupy the slot. Client IP rate counters reside in process. Run one application process per SQLite file. Document deletion, tenant isolation, independent read/write roles, encrypted backups, credential rotation, load testing and a deployment security review are outside the verified service configuration.

Report a vulnerability using a private security report if enabled by the repository owner. Exclude credentials and confidential source text from issues and logs.
