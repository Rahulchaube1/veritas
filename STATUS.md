# Release status · 24 November 2026

**Working release.** Local SDK, SQLite upserts, BM25, latent and neural retrieval, HNSW, rank fusion, trained relevance and rationale models, CPU cross-encoders, bounded citation traversal, temporal eligibility, passage-level stances, dependency-capped aggregation, abstention, exact citation spans and machine-readable output. The service includes the requested nine routes, a browser interface, a CLI and a CPU Colab notebook. The default configuration operates offline after installation.

**Executed research.** Official SciFact train and development integration, BEIR NFCorpus test evaluation on 323 queries, retrieval over 5,183 abstracts, a 48-claim neural diagnostic, a paired 80-claim neural comparison, trained JSON checkpoints, 1,440 synthetic cases, 360 held-out synthetic tests, eight component configurations, separate-search and extractive baselines, duplicate injection and candidate crowding. Coverage, timing, environment and quality checks are in results. Results were mixed. See the paper and result files before deciding whether the method suits a particular collection.

**Remaining research and engineering.** Independent human provenance and temporal labels, private-test evaluation, multilingual entailment, open-ended multi-hop answer composition, source reliability estimation, automated reconstruction of historical intervals, learning a budget policy, official long-form and table benchmarks, exhaustive model-token and per-answer cost instrumentation, GPU validation, multi-tenant authorization and distributed ingestion are outstanding. Optional SearXNG integration requires an authorized endpoint for a live trial. Colab compatibility is provided through standard notebook and CPU dependencies; Google-hosted execution has not been observed here.

**Release and outreach.** The public GitHub repository is available. GitHub Actions passed the first release checks. GitHub denied the integration permission to enable Pages. The static report is ready in docs/index.html. The Google research note is an unsent draft awaiting the intended recipient or official intake channel.
