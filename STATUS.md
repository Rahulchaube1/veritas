# Release status · 24 November 2026

**Working release.** Local SDK, SQLite upserts, BM25, latent and neural retrieval, HNSW, rank fusion, trained relevance and rationale models, CPU cross-encoders, bounded citation traversal, temporal eligibility, passage-level stances, dependency-capped aggregation, abstention, exact citation spans and machine-readable output. The service includes the requested nine routes, a browser interface, a CLI and a CPU Colab notebook. The default configuration operates offline after installation.

**v0.2 evaluation.** The original synthetic evidence-verdict score rose to 330/360. A further paired SciFact evaluation on 172 claims found 18 correct decisive answers with a matching citation and 19 incorrect decisive answers in the new scientific profile. [Study](docs/verification-v0.2.md)

**Earlier research.** Official SciFact train and development integration, BEIR NFCorpus test evaluation on 323 queries, retrieval over 5,183 abstracts, a 48-claim neural diagnostic, a paired 80-claim neural comparison, trained JSON checkpoints, 1,440 synthetic cases, 360 held-out synthetic tests, eight component configurations, separate-search and extractive baselines, duplicate injection and candidate crowding. Coverage, timing, environment and quality checks are in results. Results were mixed. See the paper and result files before deciding whether the method suits a particular collection.

**Remaining research and engineering.** Independent human provenance and temporal labels, private-test evaluation, multilingual entailment, open-ended multi-hop answer composition, source reliability estimation, automated reconstruction of historical intervals, learning a budget policy, official long-form and table benchmarks, exhaustive model-token and per-answer cost instrumentation, GPU validation, multi-tenant authorization and distributed ingestion are outstanding. Optional SearXNG integration requires an authorized endpoint for a live trial. A user reproduced the v0.1 benchmark on Colab. The revised v0.2 notebook also ran end to end on a local CPU kernel.

**Release and outreach.** The public GitHub repository is available. GitHub Actions passed the first release checks. GitHub denied the integration permission to enable Pages. The static report is ready in docs/index.html. The Google research note is an unsent draft awaiting the intended recipient or official intake channel.
