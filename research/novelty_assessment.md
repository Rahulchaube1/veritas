# Scope of the contribution

The original work in this repository is the implementation, the explicit composition of a time-eligibility gate with per-component signed votes, the paired copy-injection experiments and the recorded evaluation of this implementation. The software offers a falsifiable, reproducible comparison.

BM25, latent semantic analysis, HNSW, RRF, ONNX model inference, logistic regression, isotonic calibration, shingle resemblance, abstention and source-dependence reasoning have prior art. A worldwide algorithmic novelty claim, patent claim, general factual-accuracy advantage and comparison with Google Search would all require evidence beyond this release. [Literature review](literature_review.md)

The short name also collides with an existing fact-checking benchmark. Cite this project by repository and version. [Rothermel et al.](https://aclanthology.org/2026.acl-long.1948/)
