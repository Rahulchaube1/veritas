# Failure conditions

* A correct citation span can come from an unreliable source. Repetition and entailment do not identify truth when every visible source inherits the same upstream error.
* Shared references can concern a different subject. Same-publisher caps can merge independent reports. Missing provenance can split a single report into several votes.
* More copies can push an independent source out of a fixed candidate window. Conditional duplicate invariance does not repair lost retrieval recall.
* The temporal gate trusts supplied validity intervals. Incomplete historical versions, unknown end dates and current-state questions without metadata can cause erroneous answers or abstentions.
* NLI can classify a merely unrelated scientific sentence as contradictory. The release evaluates this using gold rationale alignment. A trained rationale filter also makes errors.
* Training and test worlds use different names and records but share templates. Effective diversity is much smaller than the row count. Calibration under this design cannot identify deployment probabilities.
* SciFact's official development set is used for public evaluation. Its private test labels and pretraining corpora are unavailable. Generalization, pretraining contamination and production source coverage remain unmeasured. [SciFact release](https://github.com/allenai/scifact)
